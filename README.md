OKTODO es una aplicación móvil enfocada en la organización de tareas, metas y eventos, integrando un sistema de motivación basado en gamificación y una mascota virtual llamada Okto que acompaña al usuario durante su progreso.

## Descripción

La aplicación busca resolver problemas comunes como la falta de organización, pérdida de motivación y dificultad para coordinar objetivos en grupo. OKTODO combina planificación personal, funciones sociales y elementos interactivos para convertir la productividad en una experiencia más dinámica.

## Funcionalidades

- Registro de tareas y eventos diarios o en fechas específicas. *(planned)*
- Visualización por prioridad y en formato calendario. *(planned)*
- Modo de concentración "Okto Work Time" con apoyo visual y reducción de distracciones. *(planned)*
- Widgets para iOS y Android con resumen de tareas. *(planned)*
- Tienda de la mascota Okto (Octo Shop) con sistema de puntos. *(planned)*
- Sistema de rachas y puntos para incentivar constancia. *(planned)*
- Creación de grupos para planear metas y eventos compartidos. *(planned)*
- Perfil personalizable con opciones de apariencia para la mascota. *(planned)*
- Bloqueo de aplicaciones seleccionadas para reducir distracciones. *(planned)*
- Modo oscuro. *(planned)*

## Público Objetivo

Dirigida a usuarios que buscan mejorar su organización personal, mantener constancia en sus metas y colaborar con otras personas en objetivos compartidos.

## Stack Tecnológico

- **Runtime:** React Native + Expo (managed workflow)
- **Lenguaje:** TypeScript
- **Navegación:** Expo Router
- **Persistencia:** SQLite / AsyncStorage (local-first)
- **Construcción:** EAS Build
- **Plataformas:** iOS y Android
